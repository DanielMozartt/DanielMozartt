# ⭐ MZTOOL — Automação e Padronização para Windows

Ferramenta de automação e padronização para Windows que **eu uso no meu dia a dia** e desenvolvo enquanto estudo automação, segurança, estabilidade e práticas de DevOps.

O MZTOOL começou simples e evolui conforme aprendo mais sobre:

- PowerShell  
- provisionamento  
- segurança e integridade de artefatos  
- estabilidade de ambientes  
- CI/CD  
- distribuição em nuvem  

Ele não é perfeito — é um projeto vivo que cresce junto com meu aprendizado.

---

## 🔧 O que o MZTOOL faz hoje

- Provisionamento automatizado de componentes do Windows  
- Instalação de softwares essenciais via Winget  
- Atualizações via PSWindowsUpdate  
- Personalização básica do perfil do usuário  
- Remoção de bloatwares e ajustes de usabilidade  
- Download de ferramentas via **Cloud** (AWS, Azure, Cloudflare)  
- Instalação automatizada do Microsoft 365 via XML  
- Criação da variável de ambiente `%MZTOOL%`  
- Provisionamento e manutenção de IaC com Terraform  
- **Pipeline CI/CD no GitHub Actions que copia artefatos, valida integridade e verifica hashes**  
- Estudos contínuos de segurança e estabilidade aplicados ao provisionamento
